MELODAN — Steam Assets

Local generator for Steam store / library art at exact required sizes, plus localized store-page section titles (Steam language suffixes). Open this file in a browser from the repo (scripts/steam_assets.html). Previews are scaled; downloads are full resolution.

Store section titles

Same workflow as Diception: one PNG per section × language. English has no suffix; others use Steam names (_schinese, _koreana, _brazilian…). Strings come from Melodan locales (regenerate with python scripts/gen-steam-title-strings.py).

Fantasy header style: cream fill, brass underline rule — not Diception’s glitch wings. CJK / Thai / Arabic use Melodan’s Noto faces from assets/fonts/.
